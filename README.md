# <div align=center>Introdução:
- **Apresentação do problema:** O projeto tem como desafio compreender como um circuito utilizando Arduino UNO funciona e apresentar uma funcionalidade útil a ele.

- **Objetivos:** montar um circuito utilizando Arduino UNO que seja capaz de reproduzir músicas presentes na memória.

# <div align=center> Metodologia:
- **Descrição dos Materiais utilizados:** 

    - **Arduino UNO:** o "coração" do circuito, é nele em que é fornecido as energias e portas para o funcionamento do circuito.
    - **Protoboard:** utilizada para conectar os dispositivos na energia e garantir maior disposição e organização no circuito.
    - **Botões:** essenciais para executar as funções do circuito, como: navegar pelas músicas, dar play ou pausar, e voltar ao menu inicial.
    - **Potenciômetro:** utilizado para alterar o contraste do LCD e garantir que o texto fique visível.
    - **Buzzer/Piezo:** utilizado para emitir as músicas armazenadas na memória do Arduino UNO.
    - **LCD:** utilizado para podermos enxergar os comandos que estamos executando e encontrar as músicas.
    - **Lâmpadas LEDs:** dão o sinal de quando uma música está tocando ou quando está pausada.
    - **Resistores:** usados para garantir que as energias transmitidas pelos fios, não acabem queimando algum componente.
    - **Fios:** para transmitir energia entre os componentes.
